Keyboard & Mouse Controls

  • Draw rectangle: Use Platform, Area, or Tunnel, then drag and release.
  • Draw slope floor: Use Polygon Floor, click points, then click first point to finish.
  • Draw one-way floor line: Use Poly Floor Line, click points, right-click or double-click to finish.
  • Place spawn point: Use Spawn Point, then click once to place a red crosshair marker.
  • Select: Click on an existing shape to view/edit properties.
  • Delete: Press Delete or Backspace when a shape is selected.
  • Cancel drawing: Press Escape.
  • Real-time Sync: Edit coordinates directly in the JSON box to update shapes. Area names can be changed in the properties panel or by editing each area's name field in JSON.
